# C Programming Practice Project

This repository contains two small C programs that demonstrate basic input, logic, and output in C.

## Programs

### 1. Palindrome Checker
File: `palindrome.c`

This program asks the user to enter a number and checks whether it is a palindrome.

Example:
- Input: `121`
- Output: `It is a Palindrome.`

### 2. Triangle Checker
File: `triangle.c`

This program asks the user to enter two angles of a triangle, checks whether they form a valid triangle, and then determines whether the triangle is right-angled.

Example:
- Input: `30 60`
- Output: `It is not a right angled triangle.`

## Build and Run

From the project root, compile the source files with GCC:

```bash
gcc palindrome.c -o palindrome
gcc triangle.c -o triangle
```

Then run either program:

```bash
./palindrome
./triangle
```

## Notes

- The repository already includes compiled executables named `palindrome` and `triangle`.
- These programs are simple console applications intended for learning and practice.
